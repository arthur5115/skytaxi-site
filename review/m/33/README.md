# T3 湖濱山城站｜建築渲染與空間配置檢視器（獨立版）

解壓縮整包後雙擊 `index.html`。保留 `assets` 子資料夾；不要在ZIP預覽視窗內開啟。

若瀏覽器限制本機檔案，Windows雙擊 `start_windows.bat`；macOS/Linux執行 `python3 start_server.py`。需Python 3；啟動器僅綁定127.0.0.1，開啟本機HTTP，停止按Ctrl+C。3D頁需JavaScript、WebGL與硬體加速。

這份為既有 `code_artifact.html` 的下載副本。只將原外部資源位址改為包內相對路徑，原建築模型程式、介面與控制未改動。資料為本頁原有版本，未換成最新全案V1.0。

需網路的剩餘項目：
無；已將原頁引用的Three r128、OrbitControls r128、Tailwind、Font Awesome 6.4.0及字型次級檔隨包提供。

資源版本：原頁明確指定Three.js r128／OrbitControls 0.128.0與Font Awesome 6.4.0，均沿用該版本；Tailwind與Google Fonts原頁未固定版本，使用原URL本次回傳內容並記錄SHA-256。未替換成其他程式庫版本。模型為原頁內嵌程序幾何，無另附不存在的GLB／STEP。
