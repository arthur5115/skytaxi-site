建立日期：2026-10-05。圖號：T1-P2-LP-01。圖面狀態：待審核。

## 使用

- `T1-P2_446m_縱斷面與淨空模型_R1_9600x5400.png`：16:9工程圖。
- `T1-P2_446m_互動計算模型_R1.html`：瀏覽器直接開啟；不需連網。可改H、w、P、車位a、額外向下扣減d；匯入控制點CSV；匯出當前數據。

## 數學模型

長度m，力tf；1 tf = 9.80665 kN。H為同一受力單元的有效水平張力。

z_c(x)=52.60+(63.10-52.60)x/446。

均布荷載下垂：f_q(x)=w x(L-x)/(2H)。

點載P位於a時：f_P(x,a)=P min(x,a)[L-max(x,a)]/(HL)。

同一工況軌道中心線：z(x,a)=z_c(x)-f_q(x)-f_P(x,a)。此處P可為等效合併點載，不代表兩車實際占用相同位置。多個獨立點載可按同一固定H模型疊加，但不能跨越受力單元混用。

移動點載的逐點下緣包絡：z_env(x)=z_c(x)-w x(L-x)/(2H)-P x(L-x)/(HL)。

這是讓a從0至L移動後，各x取最不利值所得包絡，並非同一瞬間的軌道線。包絡最低點不代表某一固定車位工況的整條實際線形；也不得用包絡導數作車行坡度。

控制點餘裕：M(x)=z_env(x)-d-C(x)。C為明確輸入的控制面高程；地形加10 m是本案規劃控制，不自動等同車底法定淨空。d表示軌道中心至下緣外廓、其他額外扣減的總量，須避免與C內含項重複計入。預設d=0是未計車體與額外包絡；介面僅報餘裕，不判定全跨安全。

## 預設為附錄C邊界比較

H=1,000 tf，P=5.88 tf，a=70 m，d=0。丘1 x=70 m、算例地形EL40、規劃控制面EL50。

w使用原方程重新反算的全精度0.29642727656848483 tf/m（原文件顯示0.296427）。這是合併受力單元的條件式輸入，不是單軌材料實重。對應丘1弦線54.247982、下垂4.247982、餘裕0；任何d>0都形成負餘裕。

跨中包絡高程49.823864 m、相對弦線下垂8.026136 m。包絡最低點約CH150.066、EL48.965341；此處沒有地形控制點，不能宣稱碰地或符合淨空。預設顯示兩位小數，全精度用於計算。

2.65 m與4.64 m是不同歷史版本的初篩／敏感度值；本模型不將其疊加於附錄C曲線，不繼承舊圖13.39／10.02 m作本版淨空結論。

## P2及模型邊界

P2承接446 m與350 m兩跨，路線條帶保留T1—P2—T2關係。第一跨解以端點位置與H給定；R1沒有求解滑鞍摩擦、EA伸長、EI、溫度—張力相容、支承位移及兩跨平衡。也未求解風振、地震、制動、輪軌局部變形或疲勞。不能把H滑桿改動稱為溫度分析。

兩條單軌獨立往復的工程模型需各自設定P、w、H及車位，再合併支承作用。附錄C的5.88 tf只用於原文同一受力單元的比較情境，並不是每軌常態設計荷載。U4-430單車最大總重2,940 kg；6人；有效載重450 kg。

本版只使用T1地面約EL37與丘1算例地面EL40的離散點，不內插成測量地形線。全跨控制面可用CSV輸入；匯入點之間不自動視為已檢核。

## 控制點匯入

CSV標題必須為 `chainage_m,ground_el_m,control_el_m`。每點x介於0與446；高程為有限數；同一里程不能重複。匯入替換原控制點；ground_el_m可留空，control_el_m不可留空。只在實際列出的控制點求M；不外插或內插淨空。
