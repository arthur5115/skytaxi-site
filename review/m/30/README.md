# 四站結構拆解 · 原始獨立版

此包為既有頁面的原始獨立版，版本與內容以各頁內的標示為準。

## 開啟方式

1. 先將整個 ZIP 解壓縮至同一資料夾。
2. 使用桌面瀏覽器開啟 `index.html`，從選單進入互動頁。
3. 四站內容可由 T1、T2、T3、T4 選單分別開啟。

幾何資料與互動程式已隨各網頁內嵌。此包提供網頁展示；模型的獨立格式檔案以另有提供的下載項目為準。

## 可選的本機服務

本機已安裝 Python 時，可使用以下任一方式啟動服務：

- Windows：雙擊 `start_server.bat`。
- macOS / Linux：在此資料夾執行 `sh start_server.sh`。
- 手動方式：`python3 -m http.server 8000 --bind 127.0.0.1`。

啟動後開啟 <http://127.0.0.1:8000/index.html>。使用完畢後，在啟動服務的終端機按 Ctrl+C 關閉。
