## 共同條件及其界線

預設H=1000 tf、w=0.29642727656848483 tf/m、P=5.88 tf、d=0。首跨固定點載x=70 m；其餘各跨先取跨中。w沿用第一跨丘1邊界反算值；不是材料重量。第2至5跨沿用相同H、w、P以比較幾何影響，不表示各跨已選定相同張力或荷載。

P、w、H為同一合併受力單元的比較設定，不可將P=5.88 tf重複施加於每軌。兩條單軌獨立往復配置的正式分析，須依各自受力單元設定車位、載重及軌道參數，再合併支承作用。

模型為固定水平張力之理想柔索拋物線近似。五跨各自給定端點與H；尚未求解P2、P4兩側變形相容、滑鞍摩擦、支承位移、EA、EI、溫度—張力、風振或其他動態效應。H調整只作敏感度比較。全線總覽是各跨結果的接續展示，不是全線耦合有限元素解。

## 公式

局部x由每跨起點歸零；全線CH=該跨起點CH+x。力tf、長度m；1 tf=9.80665 kN。

- 弦線：zc(x)=zA+(zB−zA)x/L。
- 均布荷載下垂：fq(x)=w x(L−x)/(2H)。
- 固定點載下垂：fp(x,a)=P min(x,a)[L−max(x,a)]/(HL)。
- 固定車位軌道：z(x,a)=zc−fq−fp。
- 移動點載包絡：zenv(x)=zc−fq−P x(L−x)/(HL)。
- 控制點餘裕：M(x)=zenv−d−C(x)。

包絡是不同車位各自取極值的集合，不是同一瞬間的軌道線；包絡斜率不能當作行車坡度。圖表中的弦線平均坡度也不是固定車位線的最大局部坡度。

## 檔案使用

- `虎頭埤_五跨互動計算模型_R1.html`：以瀏覽器直接開啟，不需連網。切換跨段、調整H/w/P/a/d、匯入本跨控制點、下載逐米CSV與五跨參數JSON。各跨調整在此開啟期間保留；重新開啟回復預設。
- `*_9600x5400.png`：五跨獨立圖與總覽。原第一跨圖完整保留；其CH標示等同自T1起算局部x。
- `*.svg`：可縮放向量圖；字體依賴Noto Sans CJK TC，可安裝附帶字型。
- `*_profile.csv`：預設條件下逐米資料，包含控制點與半米跨中；無控制面的位置，地形、控制面、餘裕均留空。
- `*_control_points.csv`：本跨控制點模板；未知跨只有欄名，沒有假造示例值。
- `baseline.json`、`summary.json`：基準與各跨數值摘要。
- `validation.json`、`interface_validation.json`：驗證結果。

CSV匯入欄位固定為 `x_m,ground_el_m,control_el_m`；x_m是所選跨的局部里程，不是全線CH。ground_el_m可空；x_m與control_el_m不可空，數值必須有限且x在0至L。匯入取代當前跨控制點；不接受重複x，不在點間內插淨空。空白模板需填入實際控制點才能匯入。

## 重製與驗證

Python3標準函式庫可執行 `python3 model.py` 和 `python3 build_html.py`。繪圖另需matplotlib、numpy、Pillow；執行 `python3 render.py`。首跨源碼另存first_span_source，使用共用assets字型；若首跨PNG已存在，主繪圖程式保留現檔。

先執行 `node check_interface.cjs`，再執行 `python3 validate.py`。檢核端點、正負坡跨段最低點、移動點載包絡、已知控制點、未知餘裕留空、局部／全線里程、Python/JavaScript一致性、切換與獨立狀態、CSV匯入／匯出、無效輸入。互動功能使用Node最小DOM測試；尚未作真實瀏覽器版面測試。

每張高解析度PNG均完整解碼、檢查尺寸／RGB／IEND後才替換正式檔；圖面預覽已目視檢查。包裝ZIP再驗證CRC並完整解碼內含高解析度PNG，避免曾發生的截斷PNG造成下半部黑色。

## 版本與圖面管理

LOCK：六節點、五跨距、軌道中心高程、P2/P4中間支承、U4-430、丘1/丘3飛越。

CHANGE：新增第2至5跨、總覽與五跨切換；同一比較工況可調；原第一跨PNG不變。

VERIFY：幾何、控制點位置語義、空白資料界線、計算與輸出一致、PNG完整性。

REJECT：憑空連續地形、借用印度535 m案例的張力／車底尺寸、將包絡當實際瞬間線形、將共同比較輸入宣稱為供貨設計值。

第一跨既有模型的2.65 m與4.64 m等歷史敏感度數值不再混入本版。所有圖面為待審核的幾何與條件式比較模型，不是施工核定圖。
