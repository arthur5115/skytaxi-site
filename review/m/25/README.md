# 五跨縱斷面與淨空互動計算模型 R1

解壓縮整包後，雙擊根目錄 `index.html` 即可使用。請保留子資料夾結構；不要在ZIP預覽視窗內開啟。

若瀏覽器對本機檔案有限制：Windows雙擊 `start_windows.bat`；macOS/Linux在本資料夾執行 `python3 start_server.py`。需安裝Python 3；啟動器只綁定127.0.0.1，會以本機HTTP開啟頁面，關閉時按Ctrl+C。瀏覽器需啟用JavaScript；3D頁需可用的WebGL／硬體加速。

參數已內嵌；CSV/JSON由介面匯出。附既有R1工程模型、基準資料、控制點、Python來源及原驗證紀錄。

除上述可選外站或字型外，模型、互動程式與必要本機媒體均隨包提供。原HTML保留既有外觀與功能。CAD原檔需以相容的CAD/BIM軟體開啟，不是瀏覽器啟動所需依賴。

這是既有版本的獨立下載封裝，保留原模型的版本與適用範圍；不代表最新全案V1.0，也不替代原工程審查。
