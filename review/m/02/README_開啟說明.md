# 虎頭埤長壽生活園區｜T2・T3 360° 導覽

本包為既有網站第 1 版的本機副本，保留該版網頁、模型資料、圖片與程式。

## 開啟

1. 完整解壓縮ZIP，請勿直接在壓縮檔內開啟。
2. Windows已安裝Python 3者，雙擊「啟動網頁_Windows.bat」。程式會開啟瀏覽器。
3. 其他系統在本資料夾執行 `python3 start_server.py`，依畫面顯示的本機網址開啟。
4. 使用期間保留啟動視窗；關閉時按 Ctrl+C。

`index.html` 為入口。請優先使用附帶的啟動程式，避免瀏覽器對本機檔案的模型、模組與跨頁載入限制。
啟動程式只綁定本機127.0.0.1，不公開至外網。需Python 3，不需安裝其他Python套件。

## 檔案

360°圖像全景，影像與程式隨網頁提供。

原版沒有獨立模型檔的頁面，已保留原有內嵌或JavaScript模型資料，沒有另行加入其他版本模型。

## 網路與版本

網站程式與原有資源已隨包附上。原頁上的外部網站連結、地圖服務或外站導覽仍需網路。

這是該網站版本的保存副本，並未將歷史版本的設計數據改為其他網站或最新模型數據。
